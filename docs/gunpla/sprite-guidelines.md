# 건프라 도트 스프라이트 가이드라인

2026-11-23 초안 · 이미지를 대량으로 만들 에이전트용

『기동전사 건담』 16기의 앱용 원본은 [HGUC](../../assets/sprites/first-hguc/)와 [SD·RG·MG·PG](../../assets/sprites/first-series-grades/)에 있다. 후속 작품의 원본은 [제08MS소대](../../assets/sprites/08th-ms-team/), [0080](../../assets/sprites/0080/), [0083](../../assets/sprites/0083/), [디 오리진](../../assets/sprites/the-origin/), [썬더볼트](../../assets/sprites/thunderbolt/), [쿠쿠루스 도안의 섬](../../assets/sprites/cucuruz-doans-island/), [Z건담](../../assets/sprites/zeta/), [건담 ZZ](../../assets/sprites/zz/), [역습의 샤아](../../assets/sprites/cca/), [벨토치카 칠드런](../../assets/sprites/beltorchika-children/) 폴더에 있다. [건담 UC](../../assets/sprites/uc/)는 1호기·밴시·퍼펙티빌리티의 모드를 구분한다. 같은 키트가 변형되면 해당 모드로 조립한 앞·뒤 사진을 각각 확인한다. 각 폴더의 `references.csv`에서 파일별 키트명, 반다이 상품 정보 또는 설명서와 조립 사진을 확인한다.
MG와 Ver.Ka가 둘 다 나온 기체는 키트별로 실물 앞·뒤 사진을 따로 대조한다. [MG Ver.Ka 5종](../../assets/sprites/mg-ver-ka/)과 [하이뉴 건담](../../assets/sprites/beltorchika-children/)의 Ver.Ka 그림은 MG와 별개인 Ver.Ka 등급의 그림이다. 원본 PNG는 `<기체>-mg-ver-ka.png`, 앱에 들어가는 GIF는 다른 등급과 같은 규칙으로 `<기체>-verka.gif`다.
SD의 머리 비율과 3/4 구도는 [SD 크로스 실루엣 RX-78-2 건담](../../assets/sprites/first-series-grades/rx-78-2-sd.png)을 참고한다.

크기·위치·색 수 같은 수치 규격은 샘플 검토 후 정한다(§4). **[결정]** = 사용자가 정한 것, **[제안]** = 아직 확인받지 않은 것,
표시 없음 = 샘플의 형태에서 읽어낸 것. 스프라이트 전반의 방침은 [설계 문서 §8](../superpowers/specs/2026-11-22-gunpla-tokenbar-design.md)을 따른다.

## 1. 공통

- **제작 대상 [결정]** 기체와 사양(배색·전용기)이 정해지면 [기체 목록](../../Sources/PokeTokenBar/Resources/Gunpla/machines.json)의 `grades`에서 후보를 찾고, 반다이 공식 상품 정보나 설명서에서 해당 사양으로 발매된 등급을 확인한 뒤 그린다. 예를 들어 에우고 사양 건담 Mk-II의 HG 샘플은 [HGUC 1/144 RX-178 건담 Mk-II](https://manual.bandai-hobby.net/menus/detail/1007)를 기준으로 한다. 발매를 확인할 수 없는 조합은 샘플과 대량 제작 모두에서 제외한다.
- **실물 사진 참고 [결정]** 샘플과 대량 제작 모두, 그리기 전에 해당 키트의 조립 완성품 사진을 반드시 열어 본다. 기체명·등급·사양·버전이 일치하는 사진을 사용하고, 반다이 공식 상품 사진을 우선한다. 사진에서 머리와 팔다리의 비율, 장갑의 형태와 색 분할, 방패 등 장비의 부착 위치를 확인해 §1의 공통 구도로 그린다.
- **스타일**: 도트 아트. 픽셀 경계를 또렷하게 두고 반투명·안티에일리어싱·블러를 쓰지 않는다. 배경은 투명.
- **외곽선**: 순수 검정 대신 어두운 남색 계열.
- **광원**: 왼쪽 위. 오른쪽·아래쪽 면이 어둡다.
- **색**: 기체 설정 색을 따르고, 색마다 명암 단계를 나눠 칠한다. 흰 장갑은 순백이 아니라 약간 따뜻한 흰색에 회색 그림자.
- **구도 [결정]**: 모든 등급이 같은 3/4 구도.
  - 기체가 화면 왼쪽을 향해 살짝 돌아서 있다. 얼굴이 머리의 왼쪽으로 치우치고, 머리·가슴·허리의 화면 오른쪽에 기체의 왼쪽 옆면이 보인다.
  - 기체의 왼팔은 화면 오른쪽에서 보는 이와 가깝고, 오른팔은 화면 왼쪽에서 더 멀다.
  - 같은 기체의 베이스 스프라이트는 모드나 등급을 바꿔도 시선과 몸통 방향, 팔을 내린 위치, 두 발이 바닥을 딛는 자세를 맞춘다. 무장을 든 손은 장비의 형태에 맞춰 조정한다.
  - 유니콘 1호기 각성은 빔 매그넘을 들면 총구를 아래로 향하게 하고, 실드를 장착하면 왼팔에 붙인다. MGEX 각성은 같은 직립 자세에서 왼팔을 비우고 실드 판넬 3기를 몸 주변에 전개한다. 48픽셀에서도 실드 세 장이 각각 보이도록 기체와 실드 사이에 틈을 둔다. [키트 뒷면](https://www.dalong.net/reviews/mg/mgex01/p/mgex01_111.jpg) · [실드 판넬 전개 사진](https://www.dalong.net/reviews/mg/mgex01/p/mgex01_140.jpg)
  - 유니콘 1호기 PG 각성은 최종결전판의 언체인드 모드를 기준으로 그린다. 양손을 내리고, 양쪽 무릎 옆의 흰 장갑판을 바깥쪽 아래로 펼쳐 그 사이에 녹색 프레임이 보이게 한다. 어깨 끝 장갑도 살짝 들어 올린다. [언체인드 앞면](https://www.dalong.net/reviews/cg/cgp04/p/cgp04_26.jpg) · [뒷면](https://www.dalong.net/reviews/cg/cgp04/p/cgp04_27.jpg)
  - 좌우 반전·정면 대칭으로 그리지 않는다.
- **장비 위치**는 기체 설정을 따른다. RX-78-2의 방패는 왼팔에 들고, 자쿠 II의 실드는 오른쪽 어깨에 고정한다. 이 구도에서 장비 일부가 몸에 가려져도 원래 위치를 유지한다.
- **그리지 않는 것**: 뒷모습, 배경, 바닥 그림자, 이펙트, 글자, 등급 배지(배지는 앱이 그린다).
- **등급 배지**는 [공용 PNG 8종](../../Sources/PokeTokenBar/Resources/Gunpla/GradeBadges/)을 사용한다. Ver.Ka와 MGEX 배지는 2026-11-24에 박스 참고 사진 없이 그린 초안이다. 플로팅 펫은 같은 펫 크기에서 기본 배지의 가로와 세로를 각각 50%로 줄여 표시 영역 우측 하단에 겹쳐 그린다. 도안을 수정할 때는 각 등급의 박스 표기를 참고하고, 최소 펫 크기인 48pt에서도 색과 윤곽으로 등급 변화를 알아볼 수 있는지 확인한다. [SD](https://www.dalong.net/reviews/sd/e01/p/e01.jpg) · [MGSD](https://www.dalong.net/reviews/sd/mgsd01/p/mgsd01.jpg) · [HG](https://www.dalong.net/reviews/hg/h191/p/h191.jpg) · [RG](https://www.dalong.net/reviews/rg/rg40/p/rg40.jpg) · [MG](https://www.dalong.net/reviews/mg/m172/p/m172.jpg) · [PG](https://www.dalong.net/reviews/pg/p01/p/p01.jpg)
- **금지**: 공식 일러스트·박스아트·게임 스프라이트를 따거나 트레이싱하기 (설계 문서 §2 반목표).

RX-0 1호기와 풀아머 유니콘은 장비와 사이코프레임 상태를 함께 확인한다. 닫힌 뿔과 바이저는 유니콘 모드, 전개한 V핀과 적색 프레임은 디스트로이, 전개한 V핀과 녹색 프레임은 각성으로 기록한다. BB전사 390은 유니콘 모드에서도 팔다리의 녹색 부품 일부가 보인다. 풀아머 각성은 백팩에 부스터와 중무장을 장착한 사진을 기준으로 그린다.

### 무장 장착과 가림 순서 [결정]

1. **같은 키트의 두 각도를 확인한다.** 완성품 앞 3/4 사진과 뒤 또는 옆 사진을 함께 연다. 손에 든 상태와 수납 상태가 바뀌는 장비는 이번 그림에 쓸 상태를 하나 고른다. 사진에서 고정부가 보이지 않으면 해당 조립 설명서의 장착 그림으로 확인한다. 사용한 사진은 해당 등급의 `references.csv` 행에 남긴다.
2. **생성 지시에 기체별 장착점을 적는다.** 무장 이름, 사용·수납 상태, 기체 기준 좌우, 고정부, 정면에서 가려지는 부분을 한 줄에 쓴다. 예를 들어 MS-09 돔이 바주카를 든 포즈라면 “자이언트 바주카는 오른손이 손잡이를 쥔다. 히트 사벨은 등 홀더에 수납한다. 머리·가슴·허리 장갑이 사벨의 가운데를 가리고, 등 뒤에서 실루엣 밖으로 나온 부분만 보인다”라고 지시한다. 릭 돔 II와 돔 트로펜은 각 키트의 홀더와 무장을 따로 확인한다. [MG 돔 앞모습](https://www.dalong.net/reviews/mg/m219/p/m219_02.jpg) · [등 홀더와 사벨](https://www.dalong.net/reviews/mg/m219/p/m219_05.jpg) · [MG 돔 설명서](https://manual.bandai-hobby.net/menus/detail/640)
3. **완성본을 등급별로 검수한다.** 원본을 확대해 사진과 나란히 놓고, 무장의 끝에서 손잡이·홀더까지 따라간다. 손에 든 무장은 손가락과 손잡이가 맞닿아야 한다. 등이나 뒤 스커트에 수납한 무장은 몸통 윤곽에서 끊기며, 실물에서 완전히 가려지는 부분은 그대로 생략한다. 백팩 캐논은 등 쪽 회전축에서 어깨 위로 이어져야 한다. 손으로 받쳐 어깨에 건 바주카는 손잡이와 어깨의 접점을 각각 확인한다. 손과 등에 같은 무장이 중복되거나, 수납한 무장이 가슴을 가로지르거나, 몸통에서 바로 총열이 솟는 그림은 해당 기체만 다시 그린다.
4. **앱 크기에서 다시 본다.** 투명 PNG를 48pt 상당으로 줄이고 밝은 배경과 어두운 배경에서 확인한다. 손에 든 무장의 손잡이가 흉갑과 합쳐 보이거나 등 무장이 앞으로 튀어나와 보이면 무기를 옮기는 대신 팔 자세나 보이는 길이를 조정한다. 통과한 원본에서 앱용 GIF를 다시 내보내 첫 프레임을 대조한다.

## 2. 등급별 형태

등급이 오를수록 체격과 디테일이 늘어난다. 단 RG는 체격은 HG에 가깝고 디테일이 가장 많은 예외다.

| 등급 | 체형 | 체격 | 디테일 | 색감 | 외곽선 |
|---|---|---|---|---|---|
| SD | SD | 2등신, 머리가 몸만큼 큼 | 덩어리 위주, 패널라인 거의 없음 | 밝고 채도 높음 | 굵고 끊김 없음 |
| MGSD **[결정]** | SD | SD와 같음 | MG급 (관절 프레임, 패널라인) | SD와 MG 사이 | SD처럼 굵게 |
| HG | 리얼 | 슬림, 리얼 체형의 기본형 | 큰 면에 2~3톤 셰이딩, 패널라인 최소 | 밝은 원색 | 얇고 부분적 |
| RG | 리얼 | HG와 비슷 | **가장 촘촘** — 흰 면을 회색 패널로 잘게 나눔 | 한 톤 어둡고 차분함 | 얇고 부분적 |
| MG | 리얼 | HG보다 굵은 어깨·팔다리, 넓은 스탠스 | 관절 사이로 회색 프레임이 보임 (HG < MG < RG) | 밝음과 차분함 사이 | 얇고 부분적 |
| Ver.Ka **[미정]** | 리얼 | 그림 기준 미정. 첫 Ver.Ka 그림을 그릴 때 MG와의 차이를 정한다 | | | |
| MGEX **[미정]** | 리얼 | 그림 기준 미정. 첫 MGEX 그림을 그릴 때 정한다 | | | |
| PG | 리얼 | 가장 육중, 스탠스가 가장 넓음 | 무릎·발목 등에 내부 프레임과 피스톤이 드러남 | MG와 비슷 | 덩어리가 읽히게 다시 굵게 |

- **SD 체형(SD·MGSD)**: 눈동자가 있는 큰 눈은 SD 체형에서만 쓴다. 리얼 등급은 카메라아이·모노아이·바이저. 무기·방패는 작게 줄인다.
- **첫 MGSD 샘플**은 MGSD로 발매된 기체를 골라 투명 배경의 정지 이미지 1장으로 제출한다. §1의 3/4 구도에서 머리와 몸이 비슷한 크기로 보이는지, 굵은 외곽선 안에서도 관절 프레임과 장갑 패널라인이 읽히는지 확인한다. 이 샘플로 형태 기준을 확정한 뒤 대량 제작한다.
- **구분 확인**: 이웃 등급과 나란히 놓았을 때 차이가 보여야 한다.
  - SD ↔ MGSD: 디테일
  - HG ↔ RG: 디테일
  - RG ↔ MG: 체격
  - MG ↔ PG: 내부 프레임 노출

## 3. 특수한 경우 [제안]

- **전용기(이로치)**: 기본기의 같은 등급 그림을 바탕으로 색을 바꾸고, 형태가 다른 부분(지휘관용 뿔 안테나 등)은 반영한다. 파일은 따로 둔다.
- **모빌아머·다리 없는 기체**: 같은 3/4 방향을 유지한다.

## 4. 최종 제작 사양

- **애니메이션 [결정]** 최종 앱 스프라이트에는 일정하게 반복되는 움직임을 넣는다. 프레임 수와 구체적인 동작은 샘플 검토 후 정한다.
- **기체당 그림 수**는 미정이다. 샘플을 비교한 뒤 등급마다 따로 그릴지, 같은 체형의 등급끼리 그림을 공유할지 정한다.
- **수치 규격**(크기·위치·색 수): 나중 단계. 그때 함께 볼 것 — 샘플은 등급마다 기체를 다른 크기로 그렸는데,
  앱도 `GunplaGrade.displayScale`로 등급별 배율을 한 번 더 적용한다. 크기 차이를 그림과 코드 중 어느 쪽이
  맡을지는 기체당 그림 수와 함께 정한다.
